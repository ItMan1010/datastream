## Purpose

规范前端 HTTP 请求与响应拦截器的可观测行为：鉴权头注入、错误提示以及登录失效（401）时的跳转处理。

## Requirements

### Requirement: 请求失败错误处理

前端 HTTP 客户端在请求返回非 2xx 状态码（非 401）时，SHALL 关闭已存在的提示消息并将错误向上层抛出，且 MUST NOT 抛出 `ReferenceError` 之类的运行时异常。

#### Scenario: 非 401 请求失败
- **WHEN** 请求返回非 401 的非 2xx 状态码
- **THEN** 系统关闭已存在的提示消息，并以 Promise 拒绝的形式向上层传递错误，不抛出未定义变量导致的运行时异常

### Requirement: 登录失效处理

前端 HTTP 客户端在请求返回 401 状态码时，SHALL 清除本地存储的 token，关闭已存在的提示消息，跳转到登录页，并显示「登录已失效，请重新登录！」的提示。

#### Scenario: 登录失效跳转
- **WHEN** 请求返回 401 状态码
- **THEN** 系统清除本地 token、关闭已有提示、跳转到登录页，并显示「登录已失效，请重新登录！」提示
