## MODIFIED Requirements

### Requirement: 请求失败错误处理

前端 HTTP 客户端在请求返回非 2xx 状态码（非 401）时，SHALL 关闭已存在的提示消息并将错误向上层抛出，且 MUST NOT 抛出 `ReferenceError` 之类的运行时异常。当请求返回 403 状态码时，前端 HTTP 客户端 SHALL 从后端响应体中提取可读的中文错误信息（如 `resultMsg`）作为错误向上层抛出，替代原始 AxiosError。

#### Scenario: 非 401 请求失败

- **WHEN** 请求返回非 401 的非 2xx 状态码
- **THEN** 系统关闭已存在的提示消息，并以 Promise 拒绝的形式向上层传递错误，不抛出未定义变量导致的运行时异常

#### Scenario: 403 请求失败提取可读错误

- **WHEN** 请求返回 403 状态码且后端响应体包含中文错误信息
- **THEN** 系统关闭已存在的提示消息，并以该中文错误信息作为拒绝原因向上层抛出，而非原始 AxiosError

#### Scenario: 403 请求失败无响应体回退

- **WHEN** 请求返回 403 状态码但后端响应体不包含可读错误信息
- **THEN** 系统关闭已存在的提示消息，并以通用中文无权限提示作为拒绝原因向上层抛出
